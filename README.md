# Facebook Ad Library Parser & Bot

Профессиональный инструмент для автоматизированного сбора, анализа и экспорта рекламных объявлений из библиотеки рекламы Facebook (Meta). Управляется через удобный Telegram-бот.

![Python](https://img.shields.io/badge/Python-3.11%2B-blue)
![Playwright](https://img.shields.io/badge/Playwright-Async-green)
![Docker](https://img.shields.io/badge/Docker-Ready-blue)

## Возможности

*   **Умный парсинг**: Сбор креативов (видео/фото), текстов и метаданных даже с динамических страниц.
*   **Аналитика**: Подсчет охватов (Total/EU/UK) и оценка рекламного бюджета.
*   **RSOC-анализ**: Автоматическое извлечение ключевых слов из URL и контента целевых страниц.
*   **Транскрибация**: Преобразование речи из видео-креативов в текст с переводом (Whisper AI).
*   **KW Экстрактор**: Отдельная команда для мгновенного извлечения ключевых слов из любой ссылки.
*   **Скорость**: Асинхронная архитектура (asyncio + httpx), пул соединений, блокировка лишних ресурсов.
*   **Надежность**: Устойчивость к сетевым сбоям, авто-смена прокси, повторные попытки.
*   **Docker**: Готовность к развертыванию одной командой.

## Быстрый старт

### Требования
*   **Python 3.11+** (для локального запуска)
*   **Docker & Docker Compose** (рекомендуется)
*   Токен Telegram бота (от [@BotFather](https://t.me/BotFather))

### Запуск через Docker (Рекомендуется)

Это самый простой способ запустить бота со всеми зависимостями.

1.  **Клонируйте репозиторий:**
    ```bash
    https://github.com/Helvitiss/facebook-ad-library-scraper.git
    cd facebook-ad-library-scraper
    ```

2.  **Настройте окружение:**
    Создайте файл `.env` в корне проекта:
    ```ini
    TG_TOKEN=ваш_токен_бота
    TG_USER_IDS=ваш_id_telegram
    TG_OWNER_IDS=ваш_id_telegram
    ```

3.  **Настройте конфиг (опционально):**
    Основные настройки уже заданы в `config.json`. При необходимости измените их (см. раздел Конфигурация).

4.  **Запустите:**
    ```bash
    docker compose up -d --build
    ```

Бот начнет работу. Логи доступны по команде `docker-compose logs -f`. Результаты будут появляться в папке `Exporter_Results`.

### Локальный запуск (Windows/Linux)

1.  **Создайте виртуальное окружение:**
    ```bash
    python -m venv .venv
    # Windows
    .venv\Scripts\activate
    # Linux/Mac
    source .venv/bin/activate
    ```

2.  **Установите зависимости:**
    ```bash
    pip install -r requirements.txt
    playwright install chromium
    ```

3.  **Настройте `.env`** (как в пункте Docker).

4.  **Запустите бота:**
    ```bash
    python main.py
    ```

## Конфигурация

Настройки хранятся в `config.json` и разделены по секциям.

### Основные параметры (`config.json`)

| Секция | Параметр | Описание |
| :--- | :--- | :--- |
| **scraper** | `concurrent_requests` | Количество параллельных потоков сбора (рек. 30-50). |
| | `proxy_url` | Прокси (http/socks). Можно задать через ENV `PROXY_URL`. |
| | `proxy_change_url` | Ссылка для смены IP мобильных прокси. |
| **exporter** | `min_reaches` | Минимальный охват для экспорта объявления. |
| | `exporter_workers` | Потоки для скачивания медиа и транскрибации. |
| **facebok_api** | `endpoint_url` | Точка входа GraphQL API. |

### Переменные окружения (`.env`)

Для безопасности токены и ключи лучше хранить здесь:

```ini
TG_TOKEN=123456:ABC-DEF...            # Токен вашего бота
TG_USER_IDS=12345,67890               # ID пользователей, которым разрешен доступ
TG_OWNER_IDS=12345                    # ID администраторов (полный доступ к настройкам)
PROXY_URL=http://username:password@ip:port    # (Опционально) Глобальный прокси
```

##Использование

1.  Запустите бота и отправьте команду `/start`.
2.  Отправьте **ссылку** на библиотеку рекламы Facebook (например, `https://www.facebook.com/ads/library/...`).
3.  Бот поставит задачу в очередь и начнет сбор.
4.  Вы будете получать уведомления о статусе:
    *   `Сбор данных...`
    *   `Загрузка и транскрибация...`
    *   `Отправка...`
5.  По завершении бот пришлет **ZIP-архив** с результатами.
6.  Для извлечения ключевых слов из конкретной ссылки воспользуйтесь командой `/kw`.

---

### Работа с ключевыми словами (KW)

Команда `/kw` позволяет быстро вытащить поисковые фразы, UTM-метки и мета-данные из любой целевой страницы.

1.  Отправьте `/kw`.
2.  Бот предложит прислать ссылку.
3.  В ответ вы получите список слов в моноширинном блоке (`<pre>`).
4.  **Нажмите на блок со словами**, чтобы скопировать весь список сразу.

*Поддерживается быстрый ввод: `KW <ссылка>` или `/kw <ссылка>`.*

### Команды бота
*   `/settings` - Открыть меню настроек (изменение потоков, токенов, лимитов "на лету").
*   `/kw` - Запустить процесс извлечения ключевых слов из ссылки (через диалог или напрямую).
*   `/cleanup` - Очистить временные файлы на сервере.

##Устранение неполадок

**Ошибка: `getaddrinfo failed`**
*   Проверьте интернет-соединение.
*   Убедитесь, что прокси в `.env` рабочий. Если прокси не нужен, удалите строку `PROXY_URL` или оставьте её пустой.

**Бот долго запускает парсинг**
*   Первый запуск требует загрузки модели Whisper (для транскрибации). Это может занять время.
*   Убедитесь, что `playwright install chromium` выполнен успешно (при локальном запуске).

**Проблемы с правами в Docker**
*   Если бот не может создать файлы, проверьте права на папки `Exporter_Results` и `Parser_Results` на хосте. Они должны быть доступны для записи пользователю контейнера.
