# Facebook Ad Library Parser

Автоматизированный парсер рекламных объявлений из Facebook Ad Library с Telegram-ботом для управления и получения результатов.

## Основные возможности

- **Парсинг объявлений** - Автоматический сбор креативов, текстов, изображений и видео
- **Статистика охвата** - Детальная информация по странам (EU/UK) с подсчетом просмотров
- **Расчет затрат** - Автоматический расчет рекламных расходов на основе охвата
- **RSOC-анализ** - Извлечение ключевых слов из целевых страниц
- **Транскрибация** - Автоматическая транскрибация видео с переводом
- **Telegram-бот** - Удобное управление через Telegram с интерактивными настройками
- **Экспорт** - Автоматическая упаковка результатов в ZIP-архивы
- **Многозадачность** - Очередь задач с параллельной обработкой

## Требования

- Python 3.10+
- Telegram Bot Token
- (Опционально) Прокси для обхода лимитов Facebook

1. **Клонируйте репозиторий**
```bash

```

2. **Создайте виртуальное окружение**

4. **Настройте переменные окружения**


Отредактируйте `config.json` под свои нужды (прокси, лимиты, воркеры и т.д.)

```bash

```

## Использование Telegram-бота

### Команды

- `/start` - Запуск бота и приветствие
- `/settings` - Интерактивное меню настроек
- `/cleanup` - Очистка временных файлов

### Работа с ботом

1. **Отправьте ссылку** из Facebook Ad Library
2. Бот автоматически:
   - Соберет все креативы
   - Получит статистику охвата
   - Извлечет RSOC-ключевые слова
   - Транскрибирует видео
   - Упакует результаты в ZIP
3. **Получите архив** с детальной сводкой:
   ```
   ✅ Результаты обработки:
   
   🔗 tritidal.com
      Spend: $450.23
      Reaches: 45,023
   
   Итого:
   💰 Spend: $450.23
   👁 Reaches: 45,023
   ```

### Интерактивные настройки

Нажмите `/settings` для доступа к меню:
- **🕷 Парсер**: Настройка потоков, прокси, повторов
- **📦 Экспортер**: Фильтры охвата, имена файлов
- **✈️ Telegram**: Управление пользователями и владельцами
- **⚙️ Facebook API**: Настройки API (только для владельцев)

Для списков (пользователи, владельцы):
- `[➕ Добавить]` - Добавить новый ID
- `[➖ Удалить]` - Удалить существующий ID

## Конфигурация

### config.json

```json
{
  "scraper": {
    "concurrent_requests": 45,    // Параллельные запросы
    "retries_per_creative": 5,    // Повторы при ошибках
    "proxy_url": "",              // HTTP/SOCKS прокси
    "proxy_change_url": ""        // URL для смены IP
  },
  "exporter": {
    "min_reaches": 1000,          // Минимальный охват для экспорта
    "min_reaches_eu": 0,          // Минимальный охват EU
    "min_reaches_uk": 0,          // Минимальный охват UK
    "exporter_workers": 20        // Потоки экспорта
  },
  "telegram": {
    "token": "ENV_VAR",           // Токен из .env
    "user_ids": [],               // ID пользователей бота
    "owner_ids": []               // ID владельцев (полный доступ)
  }
}
```

## Продвинутые возможности

### Прокси и смена IP

Для обхода лимитов Facebook настройте прокси:

```json
{
  "scraper": {
    "proxy_url": "http://username:password@ip:port",
    "proxy_change_url": "http://username:password@ip:port"
  }
}
```

### Фильтрация по охвату

Экспортируйте только объявления с высоким охватом:

```json
{
  "exporter": {
    "min_reaches": 10000,
    "min_reaches_eu": 5000,
    "min_reaches_uk": 2000
  }
}
```

### RSOC-анализ

Бот автоматически извлекает ключевые слова из:
- URL-параметров (`utm_term`, `keyword`, и т.д.)
- JWT-токенов в ссылках
- HTML-атрибутов целевых страниц
- Редиректов и финальных URL

## Отладка

### Логи

Бот выводит детальные логи в консоль с цветовой кодировкой:
- `ℹ️ INFO` - Информация о процессе
- `✅ SUCCESS` - Успешные операции
- `⚠️ WARNING` - Предупреждения
- `❌ ERROR` - Ошибки

### Частые проблемы

**Бот не отвечает**
- Проверьте токен в `.env`
- Убедитесь, что ваш ID в `user_ids` или `owner_ids`

**Нет данных о просмотрах**
- Facebook может не отдавать `transparency_data` для некоторых IP
- Попробуйте использовать прокси
- Проверьте, что объявления активны

**Ошибка "Rate limit exceeded"**
- Настройте `proxy_change_url` для автоматической смены IP
- Уменьшите `concurrent_requests`
